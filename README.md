# UML Class Diagram Generator

A React web app that enables users to:

- create UML classes on a design canvas
- edit class fields and methods
- attach relationships between classes
- generate Java source code from the diagram
- export or copy the generated Java code

## Features

- Interactive canvas for UML design
- Draggable class blocks
- Relationship builder for association, inheritance, composition, and aggregation
- Java code generation from entities and links
- Download generated file and copy to clipboard

## Run locally

```bash
npm install
npm run dev
```

Then open: http://localhost:5173

## Production build

```bash
npm run build
```
